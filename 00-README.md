# FluxMigrate Website Content Pack

This folder contains implementation-ready copy for the FluxMigrate website revamp: positioning, page-by-page content, navigation structure, lead forms, SEO page list, and a case-study template.

| File | Purpose |
|---|---|
| `01-site-structure-and-positioning.md` | Sitemap, core positioning statement, homepage conversion strategy |
| `02-homepage.md` | Full homepage copy |
| `03-staff-augmentation.md` | Flagship Staff Augmentation landing page |
| `04-devops-platform-engineering.md` | DevOps & Platform Engineering service page |
| `05-sre-reliability-engineering.md` | SRE & Reliability Engineering service page |
| `06-cloud-migration.md` | Cloud Migration & Modernization page |
| `07-vmware-modernization.md` | VMware Modernization & Virtualization Migration page |
| `08-technology.md` | Technology expertise page |

| `10-lead-forms.md` | Lead capture form specs (general + staff augmentation) |
| `11-seo-page-list.md` | Target URLs and search-intent notes for SEO build-out |
| `12-case-study-template.md` | Reusable case study structure |
| `13-content-marketing-calendar.md` | Resource/article topics by category |
| `14-compliance-language-note.md` | Safer wording for compliance/certification claims |

## How to use this

- Hand these files directly to a developer or copy them into your CMS page-by-page.
- File names are numbered in the order pages should be built (Phase 1 in the project plan).
- `14-compliance-language-note.md` should go to legal/compliance review before publishing anything about HIPAA, SOC 2, PCI-DSS, or GDPR.
- Metrics in `12-case-study-template.md` are placeholders — replace only with verified, real figures.
