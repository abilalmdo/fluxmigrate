# Legacy: the four-bar mark (19–26 September 2026)

The previous FluxMigrate logo: four slanted bars stepping right, forming an implied F, in an
azure-to-violet gradient. It was replaced on 26 September 2026 by the owner-supplied 07E logo (see
`../BRAND-GUIDELINES.md`). Kept for the record only; nothing in the site uses these files.

- `svg/`, `png/`, `preview/`: the old sources, exports and review screenshots.
- `concept-a/b/c-mark.svg`: the three concepts considered in 1.0 (A was adopted, B and C rejected).
- `BRAND-GUIDELINES-four-bar.md`: the old rules.
- The generators that made them are in `tools/brand/legacy-four-bar/` (`genbrand.py`, `wordmark.py`,
  `export.mjs`). Their relative paths assume the old layout, so they will not run unchanged.
