## Homepage conversion strategy

Replace the current single technical "Pipeline Assessment" form with three distinct conversion paths:

1. **Need a Project?** → "Plan a Cloud / Infrastructure Project"
2. **Need Engineers?** → "Request DevOps / Cloud / SRE Engineers"
3. **Need Help Designing Your Environment?** → "Book a Technical Discovery Call"

## Tone guidance

Copy should read like senior engineers talking to CTOs — direct, concrete, no inflated language.

Example fix:

- Before: "Managing complex system architectures purely through software execution sets to assure multi-region scaling symmetry."
- After: "Manage infrastructure through version-controlled Infrastructure as Code for repeatable, consistent deployments across environments."

- Before: "Ensoring business continuity..."
- After: "Ensuring business continuity through resilient architecture, automated failover and tested disaster recovery."
