# Compliance Language — Review Required

The current live site states that FluxMigrate's delivery model "ensures compliance" with HIPAA, SOC 2, and PCI-DSS, and references GDPR elsewhere.

**This needs review by legal/compliance before the new site goes live.** Unless FluxMigrate holds the actual certifications, contractual controls, and documented processes necessary to substantiate those claims, this wording creates legal exposure.

## Recommended replacement language

Instead of claiming FluxMigrate itself guarantees regulatory compliance, use:

> Security and compliance requirements are incorporated into architecture, access control, data handling and operational processes according to each client's regulatory environment.

## Where to apply this
- Homepage (if compliance is mentioned)
- Infrastructure Operations page
- Financial Services industry page (most exposure here, given HIPAA/PCI-DSS/SOC 2 relevance)
- Any footer/trust-badge language claiming specific certifications

## Action item
Confirm with FluxMigrate leadership which certifications (if any) are actually held before publishing any compliance claims. If none are currently held, use only the recommended language above.
